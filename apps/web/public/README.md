# Static assets

Files in this folder are served from the site root.

## Logo

- **File:** `weir-here-logo.png` (or `weir-here-logo.svg`)
- **Path:** `apps/web/public/weir-here-logo.png`
- **Usage:** The banner (desktop and mobile) shows this image in place of "WEIR HERE" text. If the file is missing, the text is shown instead.
- **Suggested size:** About 220px wide (height is scaled to 40px in the header). PNG or SVG with transparent background works best on the colored banner.
